# Savings & Investment Pool

React + Vite + Supabase application for tracking member savings and a real pooled investment operation.

## Included
- Member authentication
- Member dashboard
- Deposit requests
- Withdrawal requests
- Profit distribution history
- Referral code tracking
- Responsive mobile UI
- Supabase database integration

## Setup
1. Run `supabase/schema.sql` in Supabase SQL Editor.
2. Copy `.env.example` to `.env`.
3. Add the Supabase Project URL and anon/publishable key.
4. Run `npm install`.
5. Run `npm run dev`.

The application records real savings and investment activity. It should not be configured to promise fixed returns or to pay members from recruitment deposits.
